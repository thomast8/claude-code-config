# Agent configuration repository

This public repository owns generic Claude Code guidance, commands and role definitions. `CLAUDE.md` is the template installed into the runtime home; read it before changing workflow policy. Preserve identity placeholders and keep personal or organisation-specific details in the private orchestrator overlay.

Edit source files here, render only the changed files into the live home and verify readback. Do not copy rendered identities, credentials, sessions, caches or plugin runtime state into this repository. Keep review confidence separate from severity, preserve standing authorisation for verified fixes, and use ready PRs for requested implementation. Never merge without explicit approval.

Validate frontmatter and shell syntax for changed files. Run the private orchestrator's focused agent-parity check when changing cross-tool policy. Test role discovery in a fresh native session; file syntax alone does not establish runtime loading.
